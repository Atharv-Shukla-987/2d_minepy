# 2d_minepy
A 2d pixelated game that is inspired by minecraft made in python ,
in which you can break blocks use those to build amazing 2d structures 
and unleash your creativity

Mine , Craft and explore to your hearts content

# THEME
endless as the world is endless and you can make endless thing if you have creativity

# tech used
python and ursina

# core mechanism
• you break blocks and use those blocks to build cool builds



# features
you can break bocks

you can place blocks

you can jump

procedural world and terrain generation ( you get a different world each time)

multiple block types

2D physics for gravity, collision detection 

inventory - you can store  blocks you collected and place them when you want to

# block type and rarity

• common : stome (70% ) and dirt on top layer

• uncommon: Andesite(10%) , Granite(9%)

• Rare : Coal(4%) , Copper(3%)

• very rare : Iron(2%) , Redstone(1.5)

• legendary - Gold (0.5 % ) , emerald (0.01%)

# other details 

• Chunk System : 6 x 6 block chunk

• render distance : 24 blocks
